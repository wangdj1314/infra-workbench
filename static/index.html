API Key 管理

每个 API Key 绑定当前用户，可用于 MCP 工具 / WorkBuddy / Qoder 接入。
外部系统通过 X-API-Key 请求头携带 Key 调用 /ext/api/* 端点，同步的工作事项将自动出现在你的工作台。

外部 API 端点说明

GET /ext/api/whoami    验证 Key + 获取用户信息
GET /ext/api/work-items   获取工作项列表
POST /ext/api/work-items   创建工作项（同步对话内容）
PUT /ext/api/work-items/:id   更新工作项状态
GET /ext/api/stats         获取统计数据

MCP 服务端接入

MCP（Model Context Protocol）让 AI 客户端直接操作你的工作台数据。每个用户独立鉴权，Token 严格隔离。
接入方式：在 WorkBuddy / Qoder / Cline / Claude Desktop 等客户端的 MCP 设置中，SSE 端点填写 ，Token 填入下方生成的完整 Token。
多 Token：可同时为多个 AI 工具各生成一个 Token（如 WorkBuddy 一个、Qoder 一个），互不影响、可单独吊销。
部署文档：点击「生成部署文档(MD文件)」，AI 会生成一份 Markdown 提示词文件，粘贴给你的 AI 工具即可自动同步企业工作内容（自动排除个人使用数据）。
